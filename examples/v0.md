# Install in v0 by Vercel

Validate the idea before v0 builds it — the Demand Discovery™ MCP runs in any v0 chat.

## Install

1. In v0, click the **+** at the bottom-left of the prompt box → **MCPs** → **Custom MCP — Add MCP server details manually**.
2. Name it `Demand Discovery`, paste the URL below, leave Authentication on **None**, and click **Add**.

```
https://mcp.demanddiscovery.ai/api/mcp
```

3. **Saving isn't enough** — open **+ → MCPs** again and click **DemandDiscovery** so a checkmark appears next to it and the MCPs row reads **"1 Selected"**. Without the checkmark it's installed but not active in your chat.

## Optional but recommended: import the Skill

The free Demand Discovery Skill teaches v0 to follow the full validation flow and show every report exactly as generated.

1. Download the Skill: <https://mcp.demanddiscovery.ai/demand-discovery-skill.zip>
2. In v0, click **+ → Skills** to open the Skills panel, then click **Import ZIP** and pick the downloaded file.
3. `demand-discovery` appears in the skill list once imported.

## Before running an idea

Confirm both are on: **DemandDiscovery** shows its checkmark under MCPs, and `demand-discovery` is listed in the Skills panel.

## First question

Say this exact text in any chat:

> I would like to run this idea through the Demand Discovery connector.

A casual "should I build this?" may only get a quick answer — the exact phrase runs the full report.

## Remove

**+ → MCPs** → click DemandDiscovery to deselect it, or manage it under **Manage MCPs**. Skills: **+ → Skills** → remove `demand-discovery`.

The canonical walkthrough with screenshots for every step: <https://mcp.demanddiscovery.ai>
